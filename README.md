# Метафорическое тело эмоций — версия на вузовском стеке

Статический сайт на **чистом HTML + CSS + JavaScript** (без React и Tailwind), собранный
по материалам курса: семантика HTML5, Flexbox, Grid, позиционирование, анимации,
адаптив, JSON/Fetch и работа с DOM.

Внутри есть чат-помощник: он отвечает по материалам исследования через API DeepSeek.
Ключ хранится на маленьком локальном сервере на Python и не попадает в браузер.

## Как открыть

Самый простой способ — двойной клик по **`start.bat`** в папке проекта.
Откроется окно сервера, а сайт будет доступен по адресу <http://localhost:5174/>.
Окно сервера закрывать нельзя, пока показываете сайт.

Или из терминала (там, где лежит `server.py`):

```bash
py server.py
```

Затем открыть <http://localhost:5174/>.

Сервер отдаёт файлы из `site/` и проксирует запросы к DeepSeek. Без ключа сайт
всё равно работает: чат отвечает локально по JSON.

Если нужен только сайт без ИИ, подойдёт обычный статический сервер:

```bash
py -m http.server 5174 --directory site
```

В VS Code **Live Server** тоже покажет сайт, но чат будет только в локальном режиме:
у Live Server нет маршрута `/api/chat`.

## Ключ DeepSeek

1. Получите ключ на <https://platform.deepseek.com/>.
2. Откройте файл `deepseek.key` в корне проекта.
3. Замените строку `PASTE_YOUR_DEEPSEEK_KEY_HERE` на свой ключ и сохраните.

Сервер читает ключ при каждом запросе, поэтому перезапускать его не нужно.

**Ключ нельзя класть в `site/js/*.js`.** Браузерный код виден в DevTools, и ключ
смог бы украсть любой посетитель. Здесь ключ читает Python-сервер, а сайт
обращается только к `/api/chat`.

## Как это работает

1. `main.js` параллельно загружает `data/organs.json` и `data/about.json`.
2. `render.js` клонирует `<template>` из `index.html` и заполняет их данными.
3. `modal.js` вешает один обработчик кликов на документ (делегирование событий).
4. `theme.js` и `i18n.js` читают сохранённый выбор из `localStorage`.
5. `assistant.js` ищет в JSON метафоры по вопросу и собирает контекст для модели.
6. `chat.js` отправляет вопрос на `/api/chat`, а `server.py` добавляет ключ DeepSeek.

Данные отделены от разметки и логики: чтобы добавить орган или метафору, достаточно
отредактировать JSON и положить картинку в `images/`.

## Форма обратной связи

Открывается кнопкой **✉️ Обратная связь** в шапке.

- Поля: имя, email, сообщение, согласие на обработку данных.
- Проверка написана на JavaScript (`novalidate` отключает браузерную).
- Ошибки выводятся под полем, поле получает `aria-invalid`, фокус переходит
  к первой ошибке.
- Успешная отправка сохраняет запись в `localStorage` под ключом `feedback`
  и показывает сообщение «Спасибо».
- При повторном открытии форма очищается.

Проверить сохранённые отзывы можно в консоли браузера:

```js
JSON.parse(localStorage.getItem('feedback'))
```

## Чат с DeepSeek

Открывается кнопкой **💬** в правом нижнем углу.

**Как устроено:**

1. `assistant.js` нормализует вопрос, определяет орган и эмоцию, находит
   подходящие метафоры в `organs.json`.
2. Из находок собирается короткий контекст: цитаты, эмоции, образность,
   концептуальный анализ и статистика.
3. `chat.js` отправляет вопрос и контекст на `/api/chat`.
4. `server.py` добавляет к запросу ключ из `deepseek.key` и вызывает
   `https://api.deepseek.com/chat/completions`.
5. Ответ показывается в чате. История хранится только в памяти страницы
   и не записывается в `localStorage`.

**Если ключа нет или пропал интернет:** чат переключается в «локальный режим»
и отвечает по тем же JSON-данным без нейросети. Поэтому сайт не ломается
на защите.

Примеры вопросов:

- «Почему желудок связан со страхом?»
- «Какие метафоры передают разочарование?»
- «Расскажи о сердце»
- «Сколько всего метафор?»

## Горячие клавиши и поведение

- **Esc** — закрыть модальное окно или чат.
- **Enter** — отправить вопрос, **Shift + Enter** — перенос строки.
- Клик по фону или крестику — закрыть окно.
- Тема и язык запоминаются (`localStorage`: `theme`, `lang`).
- Ссылка `#modal-face` открывает нужное окно сразу.
- Ссылка `#feedback` открывает форму обратной связи.
