# Метафорическое тело эмоций

Небольшой сайт-справочник о том, как в романах Дж. К. Роулинг части тела передают
эмоции: «желудок ухнул», «сердце ушло в пятки», «лицо вспыхнуло».

Шесть частей тела — лицо, голова/мозг, желудок, сердце, грудь, ноги — и 31 метафора
с цитатами из книг, разбором образности, синтаксиса и концептуального смысла.

**Живая версия:** <https://zodiac454.github.io/feeling-forms/>

## Что умеет

- **Карточки частей тела.** Клик открывает окно с анализом и списком метафор: цитата,
  эмоция, образность, синтаксическая структура, концептуальный анализ, тип и частотность.
- **Русский и английский.** Кнопка `EN English` переключает интерфейс, названия органов,
  их описания и анализ. Сами метафоры остаются на русском — цитаты в них и так английские.
  Выбор запоминается в `localStorage`.
- **Светлая и тёмная тема.** Кнопка ☀️/🌙 в шапке, выбор тоже сохраняется.
- **Чат-помощник** в правом нижнем углу. Ищет ответ в данных сайта — по органу, эмоции
  и словам вопроса: «Почему желудок связан со страхом?», «Сколько всего метафор?».
  Если рядом есть прокси DeepSeek, отвечает через модель; если нет — честно работает
  в локальном режиме и не ломается.
- **Форма обратной связи** с проверкой полей на JavaScript. Сервера нет, поэтому
  сообщения складываются в `localStorage` (ключ `feedback`).
- **Прямые ссылки на окна:** `#modal-face`, `#modal-heart`, `#about`, `#feedback`.
- **Адаптив и доступность:** от телефона до широкого монитора, `aria`-атрибуты,
  закрытие по Esc, возврат фокуса, поддержка `prefers-reduced-motion`.

## Запуск локально

Проект статический: ни сборки, ни зависимостей, ни `npm install`. Но открывать
`index.html` двойным кликом не стоит — по `file://` браузер не даст загрузить JSON
и ES-модули. Нужен любой HTTP-сервер в корне проекта.

Python (обычно уже установлен):

```bash
py -m http.server 5174        # Windows
python3 -m http.server 5174   # macOS / Linux
```

Node:

```bash
npx serve -l 5174
```

Дальше — <http://localhost:5174/>.

## Публикация

Сайт развёрнут на GitHub Pages из ветки `main`, папка `/`.
Обновление — обычный пуш, Pages пересоберёт сайт за минуту-две:

```bash
git add -A
git commit -m "Обновил метафоры"
git push
```

Для Netlify, Vercel или Cloudflare Pages сгодится тот же репозиторий: указываете корень
и не задаёте команду сборки. Ничего компилировать не нужно.

## Чат и ключ DeepSeek

По умолчанию чат работает **без ИИ**: `assistant.js` сам находит подходящие метафоры
в `organs.json` и собирает ответ из цитат и анализа. Этого хватает, чтобы сайт был
полезным и полностью автономным — в том числе на GitHub Pages.

Чтобы подключить модель, нужен маленький бэкенд-прокси, потому что ключ нельзя держать
в браузерном коде: любой посетитель увидит его в DevTools. Прокси должен отдавать два
маршрута:

| Метод и путь | Что делает |
|---|---|
| `GET /api/health` | `{ "ok": true, "hasKey": true }` — есть ли ключ на сервере |
| `POST /api/chat` | принимает `{ messages: [...] }`, возвращает `{ answer: "..." }` |

`chat.js` сам проверяет `/api/health` при загрузке: если маршрута нет или ключа нет,
переключается на локальные ответы. Ключ храните в переменной окружения на сервере,
а не в файле репозитория.


## Как добавить метафору

Всё содержимое живёт в `data/organs.json`, разметку трогать не нужно. Одна метафора
выглядит так:

```json
{
  "quote": "He felt the heart rise in his face and neck. (Rowling, 2000: 261)",
  "emotion": "Смущение, когда человек теряется.",
  "imagery": "Образ поднимающегося тепла, заливающего щёки.",
  "structure": "Сложное дополнение (Complex Object): 'felt the heart rise'.",
  "concept": "Физиологическая метонимия: стыд ощущается как прилив крови к лицу.",
  "type": "Метафора (теплая → эмоция).",
  "frequency": "Единичная",
  "image": "images/metaphor-1-4.png"
}
```

Положите картинку в `images/`, допишите объект в массив `metaphors` нужного органа —
и она появится в окне, а счётчик метафор обновится сам. Новый орган — это отдельный
объект в корне массива с полями `id`, `name`, `englishName`, `image`,
`description`, `metaphors`, `analysis`; тексты описания и анализа — парами `ru`/`en`.

## Горячие клавиши

- **Esc** — закрыть окно или чат.
- **Enter** — отправить вопрос, **Shift + Enter** — перенос строки.
- Клик по фону или крестику закрывает окно.

## Технологии

Чистые HTML, CSS и JavaScript на ES-модулях. Без фреймворков, препроцессоров и сборки.
Из браузерных API — `fetch`, `<template>`, `localStorage`, `AbortController`;
из CSS — Grid, Flexbox, переменные, `@keyframes` и медиазапросы.

Внешних зависимостей только две: Google Fonts и (опционально) DeepSeek за прокси.
